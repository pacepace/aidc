# Formula/

`Formula/aidc.rb` is a **bootstrap / source-of-truth** copy of the Homebrew
formula. It exists so the formula is reviewable in this repo and so the tap can
be seeded by hand before the release automation is live.

The **live** formula that `brew install aidc` uses is generated by
`.github/workflows/release.yml` (from `release/Formula/aidc.rb.tmpl`) and
committed to the separate tap repo **`pacepace/homebrew-aidc`** on every tagged
release. A Homebrew tap MUST live in a repo named `homebrew-<name>`, so it
cannot live here.

> The `sha256` in `Formula/aidc.rb` is a **placeholder (all zeros)** and is not
> installable as-is. The real value is the sha256 of the published tarball for
> the tag, which the release workflow computes automatically.

## Publishing the tap by hand (one-time bootstrap, before automation)

The release workflow does this for you once `TAP_REPO_TOKEN` is configured. To
seed the tap manually the first time:

1. Create the public repo `pacepace/homebrew-aidc` with a one-line `README.md`
   and an empty `Formula/` dir.
2. Push the tag for the release (e.g. `git tag v1.0.0 && git push origin v1.0.0`)
   so the source tarball exists at
   `https://github.com/pacepace/aidc/archive/refs/tags/v1.0.0.tar.gz`.
3. Compute the real sha256:

       curl -fsSL -o /tmp/aidc.tgz \
         https://github.com/pacepace/aidc/archive/refs/tags/v1.0.0.tar.gz
       shasum -a 256 /tmp/aidc.tgz

4. Copy this `Formula/aidc.rb` into the tap repo's `Formula/`, replacing the
   `url` tag and the placeholder `sha256` with the real values.
5. Also render the versioned formula for the line:

       sed -e 's/__VERSION__/v1.0.0/g' -e 's/__SHA256__/<sha>/g' \
           -e 's/__VERSION_TAG__/1.0/g' -e 's/__VERSION_TAG_SAFE__/10/g' \
           release/Formula/aidc@version.rb.tmpl > /path/to/tap/Formula/aidc@1.0.rb

   (`__VERSION_TAG_SAFE__` deletes the dot — Homebrew expects class `AidcAT10`
   for a formula named `aidc@1.0`, not `AidcAT1_0`.)

6. `ruby -c` both files, commit, and push to the tap's `main`.
7. Verify on a Mac: `brew tap pacepace/aidc && brew install aidc && aidc help`.

After this, tagging a release lets the workflow keep both formulae current
automatically. See `docs/release-process.md` for the full operator checklist.
