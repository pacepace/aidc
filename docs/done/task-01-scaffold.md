# task-01: Repo Scaffold

## Objective

Lay down the directory structure and top-level files that every subsequent shard depends on. This shard creates empty directories with `.gitkeep` placeholders where needed, plus root-level metadata files. No container or CLI logic — that comes in later shards.

---

## Requirements

This shard is foundational; it does not implement specific requirements but enables CTR-*, NET-*, CLI-*, and SEC-* shards to follow.

---

## Design Context

From `docs/design-01-architecture.md`:
> The `Dockerfile` lives in `.devcontainer/Dockerfile`.

From `docs/design-04-proxy-stack.md`:
> All sidecars live in the same Docker Compose stack as Squid.

From `docs/design-05-cli.md`:
> Bash dispatcher uses convention-over-config: any executable script in `scripts/cmd-*.sh` is a subcommand.

### `Makefile`

High-level targets that wrap aidc CLI for development:

```makefile
.PHONY: help install lint smoke clean

help:
	@echo "Targets:"
	@echo "  install   Install aidc CLI into ~/.local/bin"
	@echo "  lint      Lint shell scripts with shellcheck"
	@echo "  smoke     Run smoke tests against a freshly created session"
	@echo "  clean     Remove generated artifacts"

install:
	mkdir -p $$HOME/.local/bin
	ln -sf $$(pwd)/scripts/aidc $$HOME/.local/bin/aidc
	@echo "Linked aidc -> $$HOME/.local/bin/aidc"
	@echo "Ensure $$HOME/.local/bin is on PATH"

lint:
	@command -v shellcheck >/dev/null || { echo "shellcheck not installed"; exit 1; }
	shellcheck scripts/aidc scripts/cmd-*.sh scripts/lib/*.sh proxy/refresher/*.sh proxy/policy/*.sh proxy/audit/*.sh 2>/dev/null || true

smoke:
	bash tests/smoke/run.sh

clean:
	rm -f proxy/squid/blocklist.txt
	@echo "Cleaned generated artifacts (audit data is NOT touched)"
```

## Implementation Notes

1. Use `mkdir -p` and `touch` for the structure. Don't include any logic in placeholder files beyond `.gitkeep`.
2. `scripts/aidc` is the only file that should be executable in this shard.
3. The `proxy/squid/blocklist.txt` line in `.gitignore` is intentional: the refresher generates this at runtime; we don't commit it.

---

## Anti-patterns

- DO NOT create any container Dockerfiles in this shard — those are in tasks 02-06.
- DO NOT add docker-compose content — that's task-07.
- DO NOT add real subcommand scripts — that's task-08.
- AVOID committing files that shouldn't exist yet; placeholders are `.gitkeep` only.
